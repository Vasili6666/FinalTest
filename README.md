# SauceDemo E2E Automation Testing Project

Проект автоматизированного тестирования веб-приложения [SauceDemo](https://www.saucedemo.com/) с использованием **Java**, **Selenium WebDriver**, **JUnit 5**, **Maven** и **Allure Report**.

---

## 📋 Описание задачи и тест-кейсов (ТЗ)

**Цель:** Проверка сквозных (End-to-End) пользовательских сценариев от авторизации до успешного оформления заказа.

### UC-1: Checkout Flow (один товар)
1. Авторизация под учетной записью `standard_user`.
2. Добавление определенного товара в корзину (параметризовано, например, `"Sauce Labs Backpack"`).
3. Переход в корзину и проверка присутствия товара.
4. Переход к оформлению заказа (Checkout).
5. Заполнение формы информации покупателя (First Name, Last Name, Zip/Postal Code).
6. Завершение оформления и проверка сообщения об успехе: `"Thank you for your order!"`.

### UC-2: Checkout Flow (несколько товаров)
1. Авторизация под учетной записью `standard_user`.
2. Добавление первого товара в корзину (например, `"Sauce Labs Backpack"`).
3. Добавление второго товара в корзину (например, `"Sauce Labs Bike Light"`).
4. Переход в корзину и проверка наличия обоих товаров.
5. Переход к оформлению заказа и заполнение формы данных покупателя.
6. Проверка того, что итоговая сумма товаров (Item Total) на странице проверки равна математической сумме цен выбранных товаров.
7. Завершение оформления и проверка сообщения об успехе: `"Thank you for your order!"`.

## 🛠 Технологии и стек
* **Java 17**
* **Selenium WebDriver (v4.23.0)** — управление браузерами
* **JUnit 5 (Jupiter)** — фреймворк модульного и интеграционного тестирования
* **Maven** — сборка проекта и управление зависимостями
* **Allure Report** — генерация наглядных HTML-отчетов
* **Page Object Model (POM)** — паттерн проектирования архитектуры автотестов
* **Поддерживаемые браузеры:** Google Chrome, Microsoft Edge (параметризованный запуск)
